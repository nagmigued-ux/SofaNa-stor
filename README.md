# SofaNA — متجر إلكتروني قابل للنشر

## ما الموجود؟
- واجهة متجر عربية RTL ومتجاوبة مع الهاتف.
- أقسام الملابس والحقائب والمحافظ والإكسسوارات.
- بحث وسلة مشتريات.
- Checkout حقيقي يرسل الطلب إلى الخادم.
- الدفع عند الاستلام.
- اختيار جميع الولايات الجزائرية.
- حفظ الطلبات والمنتجات في ملفات JSON.
- لوحة إدارة `/admin.html` لإدارة الطلبات والمنتجات.
- حماية أساسية عبر Helmet وRate Limit ومفتاح إدارة.

## التشغيل
1. ثبّت Node.js 18 أو أحدث.
2. انسخ `.env.example` إلى `.env`.
3. غيّر `ADMIN_KEY` إلى كلمة طويلة وقوية.
4. شغّل:
   `npm install`
   ثم:
   `npm start`
5. افتح:
   `http://localhost:3000`

## النشر
يمكن نشره على أي استضافة تدعم Node.js. قبل النشر:
- غيّر ADMIN_KEY.
- استخدم HTTPS.
- انقل قاعدة البيانات من JSON إلى PostgreSQL/Supabase/Firebase إذا أصبح عدد الطلبات كبيرًا.
- أضف صور المنتجات الحقيقية.
- أضف شركة التوصيل وأسعار الشحن لكل ولاية.
- اربط WhatsApp أو البريد/خدمة إشعارات عند الحاجة.

ملاحظة: هذه النسخة لا تنفذ الدفع الإلكتروني؛ الدفع فيها عند الاستلام كما هو مناسب كبداية.
